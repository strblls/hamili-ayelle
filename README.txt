LoveWebsite — quick setup
=========================

1. MUSIC
   Drop your song into this folder and name it exactly:  music.mp3
   (It'll fade in automatically the first time she clicks anywhere on the page —
   browsers block autoplay with sound until there's a click, so this is expected.)

2. MEMES
   Replace meme1.jpg and meme2.jpg with your actual memes (same filenames,
   any image works, it'll auto-resize).

3. THE FINAL MESSAGE
   Open script.js, right at the top there's:
       const FINAL_MESSAGE = "..."
   Edit that text to whatever you want to say. Use \n\n for a paragraph break.

4. OPENING IT
   Just double-click index.html to preview it locally.
   To actually send it to her, upload the whole LoveWebsite folder to a free host
   like Netlify, Vercel, or GitHub Pages and send the link — opening a raw HTML
   file from a phone's file system can be finicky, a real hosted link is more reliable.

That's it. Good luck. 💗
